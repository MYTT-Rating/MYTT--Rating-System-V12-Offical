MYTT MARKET — MULTI PHOTO UPDATE
================================

This version supports 1–5 photos per listing.
Photo 1 is the public card cover. Listing Details shows all photos.

IMPORTANT BACKEND UPDATE
1. Open the EXISTING MYTT Gear Market Apps Script project.
2. Replace the old script code with MYTT_Gear_Market_WebApp.gs from this package.
3. Save.
4. Deploy -> Manage deployments.
5. Edit the EXISTING Web App deployment.
6. Version -> New version.
7. Deploy.

Do NOT create a new deployment; keep the current /exec URL.
Do NOT run setupMYTTGearMarket again unless you want to reapply formatting/validation.

Existing one-photo listings remain compatible.
